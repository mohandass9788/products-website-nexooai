# NexooAI — Product Universe & Enterprise Software Showcase

A premium, data-driven software product showcase built with Next.js App Router, TypeScript, Tailwind CSS, GSAP, Lenis, Motion, and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Quality checks

```bash
npm run lint
npm run typecheck
npm run build
```

## Content

- Brand and contact placeholders: `src/config/brand.ts`
- Products: `src/data/products.ts`
- Solutions: `src/data/solutions.ts`
- Services: `src/data/services.ts`
- Industries: `src/data/industries.ts`

The contact form is intentionally frontend-only and does not send or store data.
